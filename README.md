## ⚡ Performance Budget & Optimization

- **Initial CSS Bundle**: `39.08 kB` (under 50 kB budget; `8.23 kB` gzipped).
- **Initial JS Bundle**: Modular chunking (`vendor`, `icons`, `app`) total under `90 kB` compressed.
- **Images**: Dual WebP and PNG formats with sharp enhancement. Hero image is only `13.9 kB` WebP.
- **Preloading & Fonts**: Preconnected Google Fonts (`Inter` & `Manrope`) with `font-display: swap` and preloaded hero visuals.
- **Target Metrics**: LCP < 2.0s, CLS < 0.1, INP < 200ms.

## 🛠️ Local Development & Build

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
npm install
```

### Run Local Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
